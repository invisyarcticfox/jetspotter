# JetSpotter
#### Inspired by [vvanouytsel's jetspotter](https://github.com/vvanouytsel/jetspotter) but written in TypeScript.

![Gitea package.json version](https://img.shields.io/badge/dynamic/json?url=https%3A%2F%2Fgit.itaf.uk%2Flucas%2Fjetspotter%2Fraw%2Fbranch%2Fv3%2Fpackage.json&query=%24.version&prefix=v&label=version)


### APIs this project uses:
- [adsb.lol](https://www.adsb.lol/docs/feeders-only/re-api/) *for live ADS-B data*
- [airplanes.live](https://airplanes.live/api-guide/) *for backup ADS-B data*
- [adsbdb.com](https://adsbdb.com) *for operators and countries of planes*
- [planespotters.net](https://www.planespotters.net/photo/api) *for plane photos*
- [openweathermap.org](https://openweathermap.org) *for weather data*
- [discord.com](https://docs.discord.com/developers/reference) *for sending discord notifications*
- [pushover.net](https://pushover.net/api) *for sending mobile notifications*
