# JetSpotter
### Inspired by [vvanouytsel's jetspotter](https://github.com/vvanouytsel/jetspotter) script but written in TypeScript. 

![GitHub package.json version](https://img.shields.io/badge/dynamic/json?url=https%3A%2F%2Fgit.itaf.uk%2Flucas%2Fjetspotter%2Fraw%2Fbranch%2Fv2%2Fpackage.json&query=%24.version&prefix=v&label=version)


#### APIs this project uses:
- [Cloudflare D1](https://developers.cloudflare.com/api/node/resources/d1/subresources/database/methods/query/)
- [OpenWeatherMap.org](https://openweathermap.org)
- [PlaneSpotters.net](https://www.planespotters.net/photo/api)
- [Pushover.net](https://pushover.net/api)
